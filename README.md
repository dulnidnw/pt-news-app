# pt-news-app
This app is created for the Practical Test at idsnext. 

A modern Android news application built with **Jetpack Compose**, **Kotlin**, and **Clean Architecture**.  
This app allows users to explore news articles, read detailed views, and securely sign up with password hashing.

Browse the latest news articles  
Read detailed news stories  
Sign up with field validation and SHA-256 password hashing  
Built using **Clean Architecture** and **MVVM**  
UI powered by **Jetpack Compose** + **Material 3**  
Uses **Coroutines + Flow** for reactivity  
Navigation Component for screen transitions  
----
